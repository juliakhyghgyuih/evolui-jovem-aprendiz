# EVOLUI - Jovem Aprendiz

Sistema web desenvolvido para ajudar jovens a encontrar oportunidades de Jovem Aprendiz, organizar sua jornada, preparar o currículo e treinar para entrevistas.

## Tecnologias

PHP, HTML, CSS, JavaScript, MySQL e XAMPP.

## Como rodar

1. Coloque a pasta `evolui` dentro de `C:\xampp\htdocs`.
2. No XAMPP, inicie o Apache e o MySQL.
3. No phpMyAdmin, crie o banco `evolui`.
4. Importe o arquivo `banco/evolui.sql`.
5. Copie `config.exemplo.php` para `config.php` e preencha os dados da sua máquina.
6. Acesse `http://localhost/evolui`.
